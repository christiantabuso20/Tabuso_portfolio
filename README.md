# Christian Jay S. Tabuso — Portfolio

Responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — responsive blue-themed design
- `script.js` — mobile navigation and current footer year
- `assets/profile.jpg` — profile photo

## Run locally
Open `index.html` in a web browser.

## Deploy
Upload the contents of this folder to the root of a public GitHub repository and connect it to Netlify. Leave the build command blank and use the repository root as the publish directory.
